Call a route from outside Databricks

Use the OpenAI SDK with a BenchRouter key from the dashboard:

from openai import OpenAI
client = OpenAI(base_url="https://api.benchrouter.com/v1", api_key=BENCHROUTER_API_KEY)
client.chat.completions.create(model="<route>", messages=[{"role": "user", "content": "Hello"}])

Inside Databricks, call an exposed route by its endpoint name, with a Databricks token:

client = OpenAI(base_url="{{ workspace_url }}/serving-endpoints", api_key=DATABRICKS_TOKEN)
client.chat.completions.create(model="<endpoint name>", messages=[{"role": "user", "content": "Hello"}])
