The manifest

The same schema as in a repository, plus a databricks block in the route's eval_pack:

routes:
  - route_id: support/triage
    eval_pack:
      executable:
        secret_env: [JUDGE_API_KEY]
      databricks:
        cases_table: main.support.triage_cases
        secret_scope: support-evals

Each secret_env value lives in secret_scope under a key of the same name, as a GitHub secret has the variable's name.

The app never asks for a secret value. Keep each secret in your own scope, and give the app's service principal READ on that scope. The Status screen lists any secret it cannot read yet.
